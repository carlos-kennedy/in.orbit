## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- JS

- NodeJS

- PNPM

- Inquirer

## 🚧 Projeto

O in.orbit é um APP que você pode criar e gerenciar as suas metas ! 📖⌚

Quer saber como executar? Segue abaixo:

1. Clone o repositório para o seu diretório de preferência

```CLI
git clone 'https://github.com/carlos-kennedy/in.orbit'
```

2. Baixe as dependências do projeto

```
pnpm i
```

3. Rode o projeto com o Node

```CLI
node src/index.js
```

4. Seja feliz rodando o projetão ❤
